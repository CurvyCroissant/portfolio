# Project instructions

Read and follow [AGENTS.md](./AGENTS.md), the canonical project guidance.

Preserve working features while repairing glass/motion. Verify rendered illumination and intermediate animation frames in Chromium and WebKit, including equivalent behavior under opposing OS preferences. Use reliable page light layers and real translucent/reflected materials. State attributes alone do not establish visible behavior.

Use monochrome Liquid Glass materials, page-wide/nested cursor lighting and smooth interruptible motion. Keep skills translucent, contact icon/text groups centered and equally tall, return labels concise (Back / Kembali / 戻る), the moon correctly drawn, and native page scroll within its boundaries. Do not add hero Projects/Contact buttons or selected/viewed/focus underlines, outlines or rings.

Theme changes interpolate background, materials and text/icons together on one clock. Use the global full-motion glass setup independent of OS preferences, default to light, remove visual-settings controls, and retain theme/language controls. Language changes hold the outgoing layout and animate all incoming vertical movement, heights and label widths together. Preserve media, carousel and physics identity; clamp shorter pages smoothly to their natural bottom and release temporary styles without a final jump.

Maintain the requested home/BINUS descriptions, GPA 3.90, English skill pills and accurate English/Indonesian/Japanese copy. Never restore Terminal or skeletons. Keep blur previews, selective lazy loading, spatial navigation and hover/keyboard/tap dropdowns. Use near-black dark glass, refined text feedback, sliding non-fading dropdowns, glass-unfold reveals and no arrows on image popup actions. The canonical file covers validation and responsive requirements.
